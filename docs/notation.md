# Notation

| Symbol | Meaning |
|---|---|
| $I$ | Raw digital number (DN) of a pixel |
| $BL$ | Black level |
| $g$ | Sensor gain |
| $t_\text{exp}$ | Exposure time in µs |
| $V(x,y)$ | Vignetting factor |
| $L$ | Normalised, corrected signal (DN s⁻¹) |
| $\rho$ | Surface reflectance (0–1) |
| $i$ | Index of the spectral band (G 560 nm, R 650 nm, RE 730 nm, NIR 860 nm) |
| $F_i$ | 1-point ELM calibration factor |
| $a_i, b_i$ | 2-point ELM gain and offset |
| $\mathbf{H}_i$ | Factory homography of band $i$ |
| $\mathbf{W}$ | Affine ECC fine-alignment warp |
